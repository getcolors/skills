AGENT SKILLS

skills

Repeatable operating procedures for coding agents working with Colors.

create-package-skill

Guides an agent through creating a Package Skill and a deployment, from requirements and credential boundaries to tested, authorized deployment.

npx skills use getcolors/skills@create-package-skill

refresh-oci-token

Renews the OCI CLI session token on a configured Get Colors workstation.

These are Agent Skills, not Colors Package Skills. They do not provision projects directly or carry Colors library SHA pins.
