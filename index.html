MACHINE-LEVEL AGENT SKILLS

skills

Small, self-contained skills that fix workstation problems and depend only on tools available on PATH.

refresh-oci-token

Renews the OCI CLI session token, refreshing a valid session in place or guiding browser authentication after expiry on a headless machine.

cp -r refresh-oci-token/ ~/.claude/skills/

These are not Colors Package Skills. They do not provision projects, use colors.yml, or carry library SHA pins.
